# Decision 0004: Repository-backed demo review backlog

Date: 2026-08-18

## Decision

Load six synthetic review summaries from `public/sample-reviews.csv` when the
browser opens. Each successful single-label or batch item is prepended to that
backlog in browser memory after its comparison is rendered. Verification never
starts a download automatically; the latest field-level report remains
available through the explicit **Download CSV** action at the end of the
review.

The sample backlog CSV uses one summary row per logical label review. It is
separate from the field-level CSV generated by the verification API.

## Consequences

- A first-time evaluator immediately sees a realistic mix of matches,
  mismatches, and reviews needing human judgment.
- The fixture is easy to inspect, edit, and deploy with the single Express
  service.
- Completed reviews stack up during the current page session without adding a
  database or sending review history back to the server.
- Refreshing the page clears live reviews and restores the six demo rows. This
  is intentionally not an audit log or production records-management system.
